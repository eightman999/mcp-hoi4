## About CWTools

CWTools is a library for parsing, editing, and validating Paradox Interactive script files. It supports all modern Paradox Interactive games (Europa Universalis IV, Hearts of Iron IV, Stellaris, Crusader Kings II/III, Victoria II) and targets .NET Standard 2.0.

### Features
- High-precision syntax parsing and validation
- Localization management
- Rule-based validation system
- Support for all Paradox Interactive games

### Integration

This project uses CWTools to provide enhanced validation and analysis capabilities for Hearts of Iron IV mods. The CWTools binaries are included in the `cwtools/` directory for convenience and are used under the terms of the MIT License above.
